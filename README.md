# Sepsis Flow - Model Build Repository

This repository contains the script pipeline used to reproduce the Sepsis Flow model-building workflow (outcome construction, preprocessing, train/test splitting, predictor-set generation, prevalence table generation, Day 1 and Day 2 model training, PCA summaries, export bundling, and API evaluation support).

It is organized into a staged, repo-local workflow so scripts can be run in sequence without hard-coded machine-specific paths.

---

## Implementation

### Pipeline Stages

The canonical staged scripts live under `scripts/`:

1. `scripts/01_outcomes/01_severity_scale_construction.R`
2. `scripts/02_preprocessing/01_preprocess.R`
3. `scripts/02_preprocessing/02_split_train_test.R`
4. `scripts/02_preprocessing/03_predictor_set_definitions.R`
5. `scripts/02_preprocessing/04_stratum_prevalence_check.R`
6. `scripts/03_models_day1/*.R`
7. `scripts/04_intermediate/01_build_d1_predicted_train.R`
8. `scripts/05_models_day2/*.R`
9. `scripts/06_analysis/*.R`
10. `scripts/07_export/*.R`
11. `scripts/08_evaluation/*.R`

The source of truth for execution order and dependencies is `config/pipeline_manifest.csv`.

### Runtime Structure

- `R/bootstrap.R` initializes shared config, paths, seeds, and package loading.
- `R/config.R` defines repo-local path roots (`data/`, `outputs/`) and environment overrides.
- `scripts/run_pipeline.R` runs the staged scripts in manifest order.

### Outputs

Generated outputs are written under `outputs/`:

- `outputs/models` (including `ensemble_workspace`)
- `outputs/analysis`
- `outputs/evaluation`
- `outputs/exports`
- `outputs/intermediate`

`data/processed` and `data/reference` contain pipeline-generated data objects used by downstream stages.

## Quick Start

1. **Open the repo root**
   ```bash
   cd sepsis-flow-build
   ```
2. **Confirm raw input files are present**
   Ensure the placeholder or real files exist under `data/raw/` at the paths listed above.
3. **Run the pipeline orchestrator**
   ```bash
   Rscript scripts/run_pipeline.R
   ```
4. **Or run scripts manually**
   Execute scripts one-by-one in the order defined in `config/pipeline_manifest.csv`.

Note:

- Evaluation scripts may require API availability and environment configuration (`D1_API_BASE_URL`, `D2_API_BASE_URL`).
- The prevalence table `data/reference/prevalence_all_nested.rds` is generated by `scripts/02_preprocessing/04_stratum_prevalence_check.R`.

## Development Guidelines

- Keep scripts runnable from the repo root using repo-local paths only.
- Do not introduce machine-specific absolute paths.
- Keep generated outputs under `outputs/` and generated datasets under `data/processed` / `data/reference`.
- Do not commit real study data. Placeholder/dummy files only.
- If modifying pipeline order or dependencies, update `config/pipeline_manifest.csv`.

---

## Notes on Reproducibility

- Seeds and reproducibility settings are initialized in `R/bootstrap.R`.
- The legacy `0_setup/` files remain for compatibility/reference, but the staged scripts now source `R/bootstrap.R`.
- Training/model case-weight logic has been removed from the current staged pipeline scripts (evaluation scoring weights are retained).
